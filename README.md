## 🧠 Engineering Principles

```text
Readable code over clever code.
Simple architecture over unnecessary complexity.
AI where it adds value — not where it adds complexity.
Automation over repetitive manual work.
Measure before optimizing.
Reliability is a feature.
```

I value:

- **Clean architecture** — clear separation of responsibilities
- **Maintainability** — software should remain understandable as it grows
- **Reliability** — systems should fail predictably and recover gracefully
- **Practical AI** — use AI where it creates measurable product value
- **Performance** — optimize based on evidence and real bottlenecks
- **Security** — treat security as part of engineering, not an afterthought
- **Automation** — automate repetitive processes wherever it creates real value
